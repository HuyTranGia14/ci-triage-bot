HOW TO BUILD THE SLIDE DECK
===========================

Open PowerShell and run these three lines:

    cd D:\CI_Failure_Triage_Bot\seminar
    pip install python-pptx
    python build_deck.py

You should see:

    Wrote Seminar_Topic8_AI_Assisted_DevOps.pptx  -  29 slides

The .pptx appears in this same folder. Every slide already contains the
speaker notes (View > Notes Page, or the notes pane under the slide).

If "pip" is not recognised, use:  py -m pip install python-pptx
and then:                          py build_deck.py


WHAT TO CHECK AFTER OPENING IT
------------------------------

1. Slide 18 - the two token numbers (1,465 and 1,877). Re-run
   debug_trace.py the day before and correct them if they differ.

2. Slide 11 - the table row "A real Actions run" says TBD. Measure a real
   trimmed log and fill it in, or delete that row entirely. Do not present
   an estimate as a measurement.

3. Fonts used: Cambria (headings), Calibri (body), Consolas (code). All three
   ship with Office on Windows, so they will render correctly on any lab
   machine. If you present from a Mac, check Consolas is present.

4. Export a PDF backup (File > Export > Create PDF) and put it on a USB
   stick. Also record the 2-minute demo video as the fallback required by
   section 4.3 of the requirements.


IF YOU WANT TO CHANGE SOMETHING
-------------------------------

Edit build_deck.py and re-run it. Each slide is a clearly marked block, e.g.

    # ---------------------------------------------------------------- 19 results

The colour palette is at the top of the file:

    CHERRY = the red accent (failure / our emphasis)
    NAVY   = the secondary blue (the system / the AI side)
    INK    = dark slide backgrounds
    PAPER  = light slide backgrounds

Changing one constant restyles the whole deck consistently.
